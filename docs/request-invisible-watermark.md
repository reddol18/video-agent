# 요청: 비가시 워터마크 기능 (내보내기 단계 삽입 + 견고성 측정 + 검증)

> 작성 2026-11-19 · fund_agent 세션에서 정리. 실행은 video-agent 쪽에서 진행.
> 목적: 내가 만드는 영상에 눈에 안 보이는 제작자 표식을 넣고, 공개 포트폴리오로 쓸 수 있는 수준으로 측정·문서화한다.

---

## 1. 배경

- 편집툴(Premiere·DaVinci)에서 내보낼 때 비가시 워터마크를 바로 심는 플러그인은 조사 범위에서 찾지 못함(눈에 보이는 워터마크만 있음).
- Adobe는 기업용 'Content Authenticity for Enterprise'에서 이미지·오디오·영상에 비가시 워터마크와 핑거프린트를 붙이는 방향을 발표함 → 단순 연동은 차별점이 없음.
- 따라서 이 기능의 가치는 **"넣었다"가 아니라 "어디까지 살아남는지 재봤다"** 에 있다.

## 2. 범위 (1차)

### 2.1 삽입 위치 — 최종 내보내기 단계에서 한 번만
- 완성 mp4를 다시 디코딩해서 넣지 말 것(재인코딩 손실 + 워터마크 약화).
- **최종 렌더의 마지막 인코딩 직전, 압축 전 프레임에** 넣는다.
- 씬별 슬라이드 mp4(`make_anim.py` 산출물) 단계에는 넣지 않는다 — 최종 합성 때 재인코딩으로 약해짐.
- 오디오(TTS 트랙)는 별도 방식(예: AudioSeal)으로 선택 적용. 1차는 영상만이어도 됨.
- 내보내기 옵션으로 켜고 끌 수 있게(기본값은 끔 → 측정 끝나면 결정).

### 2.2 워터마크 겹 설계
- **용도당 한 겹.** 1차는 "제작자 ID" 한 겹만.
- 같은 방식(같은 모델·같은 키)으로 두 번 넣지 않는다 — 신호 충돌로 검출값이 깨짐.
- 나중에 배포처별 유출 추적이 필요하면 **다른 방식**으로 두 번째 겹을 추가하는 구조로 설계.
- 이미 워터마크가 든 소재(예: AI 생성 이미지·영상의 SynthID 등)가 섞일 수 있음 → 공존은 하되 견고성이 떨어질 수 있으니 측정 대상에 포함.

### 2.3 출처 기록 (필수)
워터마크만으로는 소유를 증명할 수 없다(남이 위에 자기 워터마크를 덧넣으면 둘 다 검출되는 '소유권 교착' 문제).
삽입할 때마다 아래를 기록한다:
- 원본(워터마크 전) 파일 해시, 워터마크 후 파일 해시
- 페이로드(제작자 ID 등), 사용 방식·모델 버전
- 삽입 시각, 프로젝트·파일명
- 가능하면 C2PA 서명 매니페스트 부착(제3자 확인 가능한 타임스탬프). 1차에서 어려우면 기록만 하고 2차로 미룸.
- 워터마크 전 원본 보관.

### 2.4 검증 도구
- 의심 파일을 넣으면: 내 워터마크 검출 여부·페이로드·신뢰도·(기록과 대조해) 삽입 시각을 보여준다.
- CLI 먼저, 웹 UI는 선택.

## 3. 측정 (포트폴리오 핵심)

샘플 영상 몇 개(슬라이드형·실사형 섞기)로 아래 조건별 **검출률·비트 정확도**를 표로 남긴다.

| 공격/변형 | 예시 조건 |
|---|---|
| 유튜브급 재압축 | H.264, 720p, 높은 CRF(예: 28~32) |
| 해상도 축소 | 1080p → 480p |
| 크롭 | 가장자리 10% / 25% |
| 속도·프레임레이트 변경 | 1.25배속, 30→24fps |
| 일부 구간만 잘라내기 | 5초·10초 클립 |
| 화면 녹화 근사 | 재스케일 + 재압축 + 약한 색 변화 |
| 이중 워터마크 | ① 다른 방식 위에 덧넣기 ② 같은 방식에 다른 메시지 덧넣기 → 각 워터마크 검출률 |

- 화질 영향도 함께: PSNR/SSIM(또는 VMAF) 수치.
- **실패하는 조건도 그대로 기록**한다(되는 척 금지).

## 4. 후보 기술

| 후보 | 비고 |
|---|---|
| Meta Video Seal | 영상용, 프레임 단위 삽입 후 인코딩 |
| Meta AudioSeal | 오디오용 |
| Adobe TrustMark | 이미지용(프레임 적용 가능성 검토) |

- **라이선스 확인 필수**: 코드 라이선스와 모델 가중치 사용 조건이 다를 수 있음. 공개 전에 확인하고 README에 명시.
- 모델 설치(PyTorch, 수백 MB) 필요.

## 5. 진행 순서

1. **견고성 사전 실험** — 영상 1개에 Video Seal 삽입 → 재압축·크롭 후 검출되는지. 의미 없으면 여기서 방식 재검토.
2. 내보내기 파이프라인에 삽입 단계 연결 + 출처 기록.
3. 검증 CLI.
4. 3장 측정표 전체 실행.
5. README 정리 + 결과를 영상 한 편 소재로(이중 워터마크 실험 결과 포함).
